# THE VERDICT

판결이 인생이 되는 법조 커리어 시뮬레이션. 풋볼매니저처럼 판사로 40년의 커리어를 쌓으며, 법정에서 내린 판단이 인물의 삶과 세계에 영향을 줍니다.

- 서버·계정·실시간 AI 없이 브라우저에서 실행되는 오프라인 PWA
- 모바일 우선 (iPhone Safari, Android Chrome), 태블릿·PC 반응형 지원
- 저장은 기기 브라우저 안에만 됩니다 (플레이어 슬롯 2개, JSON 백업·복원 가능)

## 플레이 방법

1. **사건 받기** — 현실 시간으로 매일 10시~22시 매시 정각에 서로 다른 사건 2건이 제안됩니다. 3시간 안에 하나를 고르지 않으면 다른 재판부로 넘어가며, 동시에 맡을 수 있는 사건은 최대 5건입니다.
2. **재판 진행** — 모든 사건은 **사건·기일·증거·증인·주문·판결** 6개 메뉴에서 진행됩니다. 증거의 내용과 확보 경위를 살피고, 증인에게 질문하고, 상대의 이의·기일 연기 신청을 판단합니다. 기일마다 증인신문은 **형사 4번, 민사 6번**까지 가능합니다. 이전 버전의 '조사 체력'은 사용하지 않습니다. 필요한 자료는 재판장 주문으로 추가 제출을 요구할 수 있습니다.
3. **판결 작성** — 사건의 최소 기일을 채우면 **결론 → 주문 구성(형량·벌금·배상액 등) → 판결 이유 → 판결문 미리보기 → 최종 선고**의 5단계로 판결합니다. 결정형 사건은 한 번의 심리 뒤 결정할 수 있습니다.
4. **세상의 반응** — 판결을 내리면 판사 실력 평가, 판결문, 기사·댓글, 여론, 관계 변화가 이어집니다. 판결이 인물의 직업·재산·주거에도 영향을 미치며, 시간이 흐른 뒤 사건의 숨겨진 진실이 밝혀지기도 합니다.

### 두 개의 시간

- **현실 시계 = 사건을 받을 기회.** 새 사건은 위의 시간표에 따라 제안되고, 받아들이지 않은 사건은 다른 재판부로 넘어갑니다.
- **게임 달력 = 재판과 인물의 시간.** 현실 시간 3시간이 게임 1일로 바뀌는 방식이 아닙니다. **공판을 직접 열 때만** 게임 날짜가 앞으로 진행됩니다. 한 번에 흐르는 기간은 진행 중인 사건 수에 따라 정해집니다(기본 `14일 ÷ 진행 중 사건 수`, 최소 2일·최대 14일). 접속하지 않을 때 커리어와 나이는 자동으로 흐르지 않습니다.

### 사건과 세계

- 현재 배당 풀은 **집필 사건 60건 + 세계 시트 전용 12건 = 72건**입니다. 장기 목표는 약 40년의 커리어에서 사건이 반복된다는 느낌을 줄일 수 있도록 콘텐츠를 확장하는 것입니다.
- 세계 시트 사건에는 **했다(`did`) / 안 했다(`didnt`) / 했지만 사정이 다르다(`reason`)**의 세 갈래 진실이 있으며, 한 재판의 진실은 시작할 때 고정됩니다.
- 새 세계 시트 사건도 별도의 재판 화면이 아니라 기존 6개 메뉴의 통합 재판 시스템에서 진행됩니다.

## 홈 화면에 설치

- **아이폰 Safari**: 아래 공유 버튼 → 홈 화면에 추가
- **아이폰 Chrome**: 주소창 오른쪽 공유 버튼 → 홈 화면에 추가
- **안드로이드 Chrome**: 게임 홈 화면의 '앱 설치' 버튼 또는 메뉴 → 홈 화면에 추가

아이폰에서는 홈 화면 앱과 브라우저의 저장 공간이 따로입니다. 브라우저에서 하던 게임은 '백업 파일 저장' 후 앱에서 '저장 파일 불러오기'로 옮기세요.

## 핵심 원칙

- **판결 실력은 법정 기록과 절차로 평가합니다.** 실제 진실을 우연히 맞혔는지, 여론에 얼마나 부합하는지는 판사 실력 점수에 넣지 않습니다.
- **증거능력과 신빙성은 다릅니다.** 법정 판단에서 배제된 말은 판결 근거로 쓸 수 없으며, 기록에 남아도 믿기 어려운 말은 그 한계를 고려해야 합니다.
- **판사는 증거의 흠까지 보고, 여론은 겉모습만 봅니다.** 그 차이에서 드라마가 생깁니다.
- **1심이 최종입니다.** 항소·상급심은 없고, 판결 이후의 반전은 뉴스와 인물의 삶으로 이어집니다.

node tests/save-store.test.cjs      # 세이브 압축·복원
node tests/narrative-qa.cjs         # 집필 사건 60건의 문장·조사·구조 검사
node tests/world-sheets.test.cjs    # 세계 시트 구조와 세 갈래 진실 검사
