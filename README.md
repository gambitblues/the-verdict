# THE VERDICT

판결이 인생이 되는 법조 커리어 시뮬레이션. 풋볼매니저처럼, 판사의 판단 하나하나가 숫자로 돌아오고 세계가 그 결과에 반응합니다.

- 서버·계정·실시간 AI 없이 브라우저에서만 도는 오프라인 PWA
- 모바일 우선 (iPhone Safari, Android Chrome)
- 저장은 기기 브라우저 안에만 됩니다 (플레이어 슬롯 2개, JSON 백업 가능)

## 플레이 방법

1. **사건 받기** — 매일 10시~22시 사이 매시 정각에 새 사건이 들어옵니다. 하루 최대 4건, 진행 중 최대 12건.
2. **재판일 진행** — 재판일마다 조사 체력 4로 증거를 조사하고, 쓸지 뺄지 정하고, 증인에게 질문합니다. 상대 변호사가 이의 제기나 재판일 미루기를 신청하면 받아들일지 정합니다.
3. **판결** — 최소 재판일(사건 중요도에 따라 2~4번)을 채우면 판결합니다. 판결 이유 1~2개를 함께 고릅니다.
4. **세상의 반응** — 📋 판결 요약과 함께 법리 칼럼, 법원 출입기자의 뒷이야기, 시민광장 반응이 바로 나옵니다. 판결이 쌓이면 언론이 흐름을 읽고 서사를 이어가며, 판결 리뷰 점수는 게임 시간 3일 뒤 공개됩니다. 몇 주 뒤 그 사건의 숨겨진 진실이 뉴스로 드러나기도 합니다.

현실 3시간 = 게임 1일. 재판일 사이에는 현실 시간으로 10분(미루기를 받아주면 30분)을 기다리며, 그동안 다른 사건을 진행할 수 있습니다.

## 홈 화면에 설치

- **아이폰 Safari**: 아래 공유 버튼 → 홈 화면에 추가
- **아이폰 Chrome**: 주소창 오른쪽 공유 버튼 → 홈 화면에 추가
- **안드로이드 Chrome**: 게임 홈 화면의 '앱 설치' 버튼 또는 메뉴 → 홈 화면에 추가

아이폰에서는 홈 화면 앱과 브라우저의 저장 공간이 따로입니다. 브라우저에서 하던 게임은 '백업 파일 저장' 후 앱에서 '저장 파일 불러오기'로 옮기세요.

## 핵심 원칙

- **판결 실력은 증거와 절차로만 매겨집니다.** 여론과 숨겨진 진실은 점수에 들어가지 않습니다.
- **판사는 증거의 흠까지 보고, 여론은 겉모습만 봅니다.** 이 차이에서 드라마가 생깁니다.
- **1심이 최종입니다.** 항소·상급심은 없고, 판결 이후의 반전은 뉴스로만 일어납니다.

## 실행

```bash

# http://localhost:8080 접속
```
