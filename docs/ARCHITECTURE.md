# 구조

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 진입점. 플레이어 슬롯 부트스트랩 후 아래 스크립트를 순서대로 로드 |
| `game.css` | 전체 스타일 (기존 스타일시트 7개를 원래 적용 순서대로 합침) |
| `deep_case_engine.js`, `story_engine.js`, `case_pack_engine.js`, `continuity_engine.js`, `npc_life_justice.js`, `family_engine.js` | 사건 생성, 숨겨진 진실, 사건팩 검증, 인물 생애 |
| `curated/part1~3.js`, `curated/registry.js` → `curated_cases.js` | **집필 사건 30건.** 사건마다 4막 서사, 양측 주장, 증거 3개(보여주는 것·한계), 사연 있는 증인 3명, 판결별 '그 후', 숨겨진 진실. 원본은 `curated/`, 게임이 읽는 묶음은 `node tests/build-curated.cjs`로 만듦 |
| `save_store.js` | 세이브 읽기·쓰기. 큰 세이브는 압축(fflate 내장)해 저장 |
| `game_runtime.js` | 세계·NPC·사건·세이브·홈·태블릿 기본 런타임 |
| `game_hearings.js` | 현실시간 사건 배당, 다른 재판부, 세이브 스냅샷, 판사 만들기, 사건 요약 |
| `game_professions.js` | 검사·변호사·로펌, 첫 배당 4건, 명성, 법정 화면 4탭 배치 |
| `game_ui.js` | 가상 언론사 20곳, 시계 하나 홈, 태블릿 |
| `trial_core.js` | **재판 엔진.** 순수 계산 함수만 있음 (DOM·저장·전역 없음) |
| `media_desk.js` | **미디어 데스크.** 판결을 요약·칼럼·출입기자·시민광장 반응으로 바꾸는 순수 함수 (DOM 없음) |
| `app_install.js` | 홈 화면 앱 설치 안내 카드 (iOS/Android/앱 내 브라우저 구분) |
| `trial_play.js` | **재판 루프.** 법정 '심리·판결' 화면을 맡아 재판일·증거·증인·상대 신청·판결·언론 반응을 처리 |
| `content-packs/` | 사건 원형 100개와 서사·증인·법정 문서 팩 |
| `sw.js` | 오프라인 캐시. 배포마다 `CACHE` 이름을 올림 |

`game_*.js`는 예전 패치 파일들을 순서대로 합친 것이며, 이제 이 파일들이 원본입니다. 새 기능은 패치를 덧붙이지 말고 해당 파일을 직접 고치거나 `trial_*`처럼 독립 모듈로 추가합니다.

## 재판 엔진 (`trial_core.js`)

입력 → 계산 → 출력 구조입니다.

- **입력**: 사건 변수(숨겨진 진실, 증거별 힘·흠 종류·흠 크기·겉보기 강도), 인물 변수(증인 태도·믿을 만한 정도·기억, 상대 변호사 스타일), 상황 변수(조사 체력, 화제성·여론·분열도)
- **계산**: `gauge()`가 '증거로 보여준 정도(P)'와 '아직 남은 의문(D)'을 계산하고, `skill()`이 판결 실력을 계산합니다.
- **출력**: 재판일 결과, 판결 실력, 판결 리뷰(60% 판결 실력 + 20% 여론과 맞은 정도 + 20% 평가자 3명 평균), 기자 헤드라인, 시민 반응

지켜야 할 규칙 (테스트로 고정됨):

1. 여론은 `gauge()`와 `skill()`에 들어가지 않습니다.
2. 숨겨진 진실은 증거의 흠과 증언을 통해서만 드러나며 점수에 쓰이지 않습니다.
3. 결정은 키로 저장됩니다. 같은 결정을 반복해도 점수가 쌓이지 않고, 결정을 바꾸면 이전 것을 대체합니다.
4. 이의 제기·미루기는 상대가 신청했을 때만 나오는 카드이며, 신청이 정당했는지(`valid`)에 따라 맞는 대응이 달라집니다.
5. 같은 사건 원형은 최근 20건 안에 다시 나오면 표시되고, 다시 나올 때는 숨겨진 진실이 바뀝니다.
6. 판결 방향은 판결 ID와 라벨로 명시적으로 판별합니다(`direction()`). `notguilty`가 유죄로 잡히던 문제를 막습니다.

## 재판 루프 (`trial_play.js`)

- 사건을 처음 열 때 `ensure()`가 숨겨진 층을 굴리고, 증인은 사건 원형의 역할로 새 NPC를 만듭니다(검사·변호사·다른 사건 인물과 겹치지 않음).
- 재판일마다 조사 체력 4. 조사·증거 결정·증인 질문은 1씩 쓰고, 상대 신청에 답하는 것은 체력을 쓰지 않습니다.
- `재판일 마치기`에서 막판 반전(중요도에 따라 11~15%)을 판정하고, 여론을 갱신하고, 다음 재판일까지 대기 시간을 겁니다.
- 판결 시 판결 이유를 고르면, 기존 선고 처리(`conclude`)를 한 번 호출해 명성·인물 생애·가족 등 기존 시스템이 모두 반응하게 합니다.
- 법정 화면은 탭 페이지(`ui.t4tab`)로 나뉘고, 증거·증인은 한 장씩 넘기는 카드(`ui.t4ev`, `ui.t4w`)입니다. 아래 고정 행동 바(`dock`)가 지금 할 일 하나를 보여줍니다.
- 30초마다 판결 리뷰 공개와 진실 공개 뉴스를 확인합니다.

조정값은 파일 맨 위 `tuning` 블록에 있습니다.

## 미디어 데스크 (`media_desk.js`)

`react(사건 맥락, 데스크 상태)` → `{summary, anomalies, column, beat, community, narratives, state}`.

1. 사실 고정: 요약은 엔진 값 그대로 만들고, 모든 문장이 이 값을 인용합니다.
2. 이상치 → 칼럼 주제. 칼럼은 숫자, 출입기자는 관계, 시민광장은 감정으로 서로 다른 원인을 댑니다.
3. 출입기자 기사 강도(1~3)는 `state.narratives`의 누적 수준으로만 오릅니다.
4. 시민광장 모드(찬양·비판·논쟁)를 먼저 정하고, 모드와 극성이 맞는 밈만 씁니다. 중대 사건(살인·성범죄)은 `heavy:true` 밈만 허용합니다.
5. `state.recent`에 최근 사용 문구를 남겨 다음 판결에서 재사용을 피합니다.

데스크 상태는 `S.press4.media`에 저장됩니다. 규칙은 `tests/media-desk.test.cjs`로 고정되어 있습니다.

## 집필 사건 (`curated/`)

- 출제 풀은 집필된 30건으로 제한합니다(형사 강력·성범죄·가족·금융·재산·명예·전문직·폭력·공공·민사, 기존 비율 유지).
- 본문의 `{A}` `{B}` `{L}` `{W1..3}`는 당사자·상대 변호사·증인 이름으로 채워지고, 조사는 `{A|이}`처럼 받침에 맞게 붙습니다.
- 성별을 단정하는 단어는 쓰지 않습니다(인물 성별이 무작위이기 때문).
- `node tests/narrative-qa.cjs`가 남은 자리표시자, 이음새(`이(가)`, `혐의 혐의` 등), 조사 오류, 문장 끝, 구조(증거 3·증인 3·4막·결말·진실), 문장 중복률(3% 미만)을 검사합니다.

## 세이브

- `localStorage`가 주 저장소, IndexedDB에 최근 스냅샷 3개.
- 120만 자를 넘는 세이브는 deflate로 압축해 `Z1:` 접두어와 함께 저장합니다(약 7배 작아짐). 큰 세이브는 0.7초 쉬었다가 한 번에 쓰고, 앱이 가려지거나 닫힐 때 반드시 씁니다. 읽는 쪽은 모두 `VerdictStore`를 거칩니다.
- 판결 후 반년이 지난 사건은 기록·결과 화면과 이후 사건에 필요한 것만 남기고 심리 대본을 덜어냅니다(`c.archived`).
- 가족 인물은 필요할 때만 만듭니다(인물 기록을 열 때, 혼인·출생 같은 사건이 생길 때). 아무 일도 없었던 가족은 정리했다가 같은 이름·나이로 다시 만들어집니다.
- 인물의 연도별 재산 기록은 최근 5년, 직업·관계 기록과 기억은 최근 것만 보존합니다.
- 활성 프로필은 `the_verdict_alpha_1`에만 있고, 슬롯(`verdict_player_save_N`)에는 프로필을 바꿀 때만 복사합니다.
- `node tests/long-career.mjs [년수]`가 한 커리어(기본 40년, 연 10건 안팎)를 판결까지 돌리며 5년마다 나이·사망·가족 연결·법조 경력·옛 사건 열람·세이브 크기를 확인합니다. 40년 결과: 인물 약 2,500명, 사건 350건, 저장 약 134만 자(압축 전 813만 자), 불일치 0.
- 기본 사건팩 원문은 세이브에 넣지 않고 ID와 계산값만 저장합니다.
- 재판 상태는 사건마다 `S.cases[id].trial4`, 언론 상태는 `S.press4`(기자 호감도, 판결 리뷰, 미디어 데스크 서사)에 있습니다.
