# P3-11 — Terra 세계 시트 제한적 보수 및 재검증

## 구현
- `server/worker/src/terra_case_generator.cjs`의 `repairWorldSheet(candidate,currentSheet,errors,options)`는 모델이 작성한 **정식 세계 시트의 누락/구조 오류만** 대상으로 Terra 호출을 추가 수행한다.
- 모델 응답을 검증할 때 기존 후보의 `id`, 공개 사건 카드, 세 세계의 `act`/`motive`/`cause`, 개별 `records` 원문, 증인 `saw` 등은 **문자열 단위로 보존**되어야 한다. 변경 시 `repair-rejected`.
- `tests/terra-generate.cjs`는 사건 후보를 임의로 다시 생성하지 않는다. 정식 세계 시트 생성 이후 QA 실패 시, 오류를 전달해 **최대 2회만 추가 모델 호출**하고 매회 `tests/terra-handoff-qa.cjs`에서 다시 구조·프로토타입 재판 검증한다.
- 최종 성공한 시트만 `pending/<id>`에 파일로 저장한다. 기존 폴더 덮어쓰기 금지. `.gitignore`의 `pending/` 제외 규칙으로 생성된 비공개 잠긴 진실의 우발적 Git 반영을 방지한다.
- `server/worker/test/terra-world-sheet-handoff.test.js`는 올바른 시트 수정과 AI의 잠긴 증거 변조 거부를 모의 API로 확인한다.

## 중요한 제한
- 구조적 보수는 새로운 사건 사실을 창작하지 않는다. 법률·의학·감정의 실질적 검증은 운영자에게 남긴다.
- **원형 후보 자체가 생성 검수에 실패하면 재작성 호출을 자동 진행하지 않는다.** 잘못된 진실을 세운 후보는 제작자가 소재 단계부터 다시 작성해야 한다.
- 모델의 응답 크기가 너무 크거나 JSON을 반환하지 않으면 생성이 실패할 수 있다. 토큰·비용 제어, 타임아웃, 실제 모델 권한은 실 API 사용환경에서 확인할 필요가 있다.
- 생성기는 오직 개발자 명령 `node tests/terra-generate.cjs --execute seed.json`에서 실행하며, 게임 브라우저·클라우드 배포·백그라운드 스케줄에 연결하지 않는다.
- 기존 사건 100건 및 사용자 저장 데이터, 운영 `main`은 변경하지 않는다.
