# THE VERDICT — 법조인 생태계 및 새 게임 첫 배당 (개발본)

브랜치: `develop` — 공개 Pages 미배포

## 구현
- 새 커리어: 100개 팩 설치 확인 후 중복 없는 사건 4건을 자동 배당. 초기 고정 사건(미진행분)은 다른 재판부 이관 처리. 해당 현실 일자 신규 수락 4건으로 집계.
- 법조인 생성 비율: **활성 사건 수** 기준 법관 약 0.6배(플레이어 포함), 검사 1배, 변호사 2배. 생성된 인물은 고유 ID/경력/인맥 기록을 유지하며 사건 감소 시 삭제하지 않음.
- 초기 사건 4건의 목표 인력: 판사 3(플레이어 포함), 검사 4, 변호사 8. 100개 사건 원형에 대해 NPC를 한꺼번에 만들지 않음.
- 8개 가상 로펌/법률사무소 + 국선변호인 명부, 등급 1–5, 사건 조사 지원력과 수임료 구분.
- 피고인의 재산·부모 경제력·사회적 지위를 반영한 사선/국선 선임. 자력은 소송구조 설계 변수이며 사법적 유무죄 판단과 구분.
- 검사: 경력·공소수행력·증거 분석력; 변호사: 경력·소속 로펌·변론/증거 분석·수임 평판·직업 윤리.
- 경험 많은 법관과 검사의 퇴직 후 변호사 진출, 변호사의 로펌 이직/국선 중심 전환/사선 복귀를 연간 생애 변화로 기록.
- 법정에서 변호인의 증거별 반박 수준과 검사 반대논거를 실제 심리 기록에 저장. 평가 로직은 변론의 조사 부담만 바꾸며 사건의 객관적 진실이나 자동 유죄/무죄를 바꾸지 않음.
- 100개 사건의 개별 장소·기초 행위·동기·상대방 주장·증인 직책/질문을 사건 ID에 연결. 17건 사망 및 16건 성범죄는 별도 법의학 상세 항목 보강.

## 수행한 모의 QA
- 100/100 사건 원형 및 사전 작성 상세 데이터 ID 연결 검사 통과.
- 100/100 사건의 핵심 증인 직책 및 질문 3개 존재. 첫 증인 역할 100건 서로 다름.
- 문법 검사, 개발 인덱스 및 PWA 캐시 연결 통과.
- 최초 배당 모의: 4개 사건 원형 모두 서로 다르고, 시작 고정 사건 이관, 진행 슬롯/자동 수락 4건으로 기록 확인.
- 대상 4개 사건에서 판사 3, 검사 4, 변호사 8 인력 풀 생성 확인.
- 변호사 선임과 소속 로펌·등급 저장, 변론력에 따른 기일 발언/판결 검토 점수 차이, 인물 카드의 법조인 정보 표시 검사 통과.

## 미완성·주의
- 100건의 법률 구성요건 및 형량/벌금 액수는 **가상 사건의 잠정 구형**. 모든 사건에 대한 개별 법률전문가 검수 완료로 표시하지 않음.
- 100건 사건별 배경 설정·증거 연결을 구조화했지만 100편 모두 독립적인 장편 드라마/분기 후일담 수준의 수동 창작·플레이 검수를 마친 것은 아님.
- HTML 모의 통합 테스트만 실시. 실제 iPhone/Android·브라우저 저장/장기 시간 시뮬레이션 종단 테스트 전.
- 국선 변호사도 실력자가 될 수 있음. 수임 감소를 법률 역량 부족과 동일시하지 않는 밸런스 조정 필요.
- 기존 세이브는 시작 4건을 소급하여 생성하지 않도록 신게임 조건 체크. 이전 저장으로의 마이그레이션/장기간 데이터 검증 필요.
- 사용자 배포 명령 전까지 `main` 병합 금지.
