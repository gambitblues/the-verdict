# THE VERDICT P3-6 — Terra 사건 초안 입고 게이트

## 실제 구현 범위 (develop)
- `server/worker/src/terra_case_pipeline.cjs`는 네트워크 연결이 없는 순수 데이터 검증 모듈이다.
- `validateDraft(candidate)`는 사건 장면, 출처, 인과관계, 최소 3개 증거, 증인, 세 갈래 세계(did/didnt/reason)를 검토한다.
- `makeReview(candidate,checks,reviewer)`는 독립 검토자와 8개 체크리스트를 요구한다. 체크 자체는 사람의 검수 완료 선언이지 법률의 자동 인증이 아니다.
- `admit(candidate,approval,inventory)`는 명시적으로 승인된 사건만 별도 **테스트 재고 배열**에 넣는다. 승인 정보가 없거나 초안과 지문이 일치하지 않으면 거부한다.
- 비슷한 사건을 막기 위해 유형·핵심 원인·행동·증거 종류에 대한 정규화 지문을 비교한다. 의미상 완전한 유사성 분석이 아니라 보수적 1차 필터다.
- 500개 사건 원형 목표(살인 85, 성범죄 80, 폭력 40, 금융 50, 재산 45, 명예 45, 민사 25, 가족 55, 전문 45, 공공 30)를 초과 등록하지 않는다. 기존 91건의 실제 배당 확률은 변경하지 않는다.
- 나무위키 등 2차 자료는 참고 배경으로만 기록하고, 판례·법령 확인의 대체 근거로 인정하지 않는다.

## 입고 가능한 초안 구조
`format: "verdict-terra-candidate/v1"`; `status: "draft" | "review"`.
기본 항목: `id`, `card`, `source`, `premise`, `scene`, `records`, `witnesses`, `worlds`.
증거에는 제목·확보 경위·입증 한계·초기 공개 여부를 표시한다. 모든 세계에서 증거 원문과 증인 관찰 범위를 별도로 채워야 한다.

## 아직 연결하지 않은 부분
1. Terra 모델 호출, 실제 판례 API 수집, 실존 판례·기사의 URL 본문 확인.
2. `world-sheets/cases` 기존 상세 스키마로의 변환, 기존 `tests/world-sheets.test.cjs` 전체 검증과 재판 완주.
3. 관리자 승인 저장소/관리자 권한 인증/서버 공유 재고 및 운영 UI.
4. 신규 승인 사건을 실제 게임 배당 흐름에 연결하는 작업.
5. 장기 플레이·모바일·2인 공유 세계·생성 비용 및 실패 복구 검증.

**안전 원칙:** 별도 테스트 재고에만 등록하며 운영 `main`, 기존 `world_sheets.js`, 91개 원형, 실제 사용자 저장 데이터는 변경하지 않는다. 위 항목들을 완수하고 확인한 뒤 배당 연결을 진행한다.
