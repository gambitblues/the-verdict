# THE VERDICT — 공개 판례·기사 참고 사건 개발 기준 (P3)

## 목표
공개 판례와 신뢰할 만한 기사의 **법적 쟁점·증거 유형·수사상 공백**을 참고하되,
이름과 장소만 바꾼 실존 사건 복제는 만들지 않는다.
새 사건은 독립적인 가상 인물·행위·시각·증언·증거로 구성하고 생성 시 진실을 잠근다.

## 확인한 공식 자료 소스 (2026-11-04)
- 국가법령정보 공동활용: https://open.law.go.kr/LSO/openApi/guideList.do
  - 판례 목록·본문 조회 공식 API 제공. 공개 판례 확인용.
- 법원 사법정보공유포털: https://openapi.scourt.go.kr/kgso000m02.do
  - 판례·사건정보 데이터 API 제공 안내. 접근권한·허용범위·약관 확인 후 사용.
- 법원 사법정보공개포털: https://www.scourt.go.kr/judiciary/information/public/
  - 비실명화된 공개 판결문 등 안내. 공개되지 않은 사건의 세부 신상은 수집하지 않는다.
- 언론사 기사: 원문 링크와 제목, 매체명, 날짜, 실제로 참고한 쟁점을 별도 기록.
  뉴스 기사 전문을 복제하거나 사실관계가 확인되지 않은 보도를 사건의 확정 진실로 사용하지 않는다.

**현재 개발 상태:** 이 문서는 공식 API 연동을 완료했다는 뜻이 아니다. 기존 저장소에는
판례 조회용 인증키·관리자 검수·공유 사건 재고 등록 기능이 없으므로 **네트워크 자동 수집 및 운영 사건 자동 등록은 아직 막아둔다.**
기존 `CasePackEngine`에 `scene`·`references` 구조를 선택적으로 추가한 것만 반영했다.

## 사건 원형 참고 항목
```json
{
  "scene": {
    "location": "다세대주택 거실",
    "observed": "타일에 혈흔이 남아 있고 식탁 옆에 깨진 유리컵이 있다.",
    "uncertainty": "혈흔의 발생 경위와 유리컵을 깨뜨린 사람은 확인되지 않았다."
  },
  "references": [
    {
      "type": "precedent",
      "title": "실제 확인한 공개 판례의 제목",
      "publisher": "공식 제공기관",
      "published": "YYYY-MM-DD",
      "url": "https://공식-자료-주소",
      "learning": "참고한 증거 쟁점 또는 법리 (사건 사실 복제 금지)"
    }
  ]
}
```

`scene`은 **관찰·확정된 상황 vs 설명이 필요한 부분**을 분리한다.
잔혹하거나 민감한 사건도 현장의 손상, 피해 상황, 의료/감식 기록 등을 구체적으로 다룰 수 있지만
선정적 표현만 늘리지 않고 법정 판단의 재료가 되는 정보를 넣는다. 미성년 피해자와 성폭력 피해자를
불필요하게 상세히 묘사하거나 실제 피해자를 식별할 수 있는 개인 정보는 넣지 않는다.

## 실제 신규 사건 승인 절차
1. 편집자가 공개 판례·기사의 제목, 출처 URL, 날짜, 참고할 법적 쟁점을 확인한다.
2. 법적 쟁점·증거 구조·수사상 확인되지 않은 부분만 추출하고 고유한 실제 사건 신상과 원문 서술은 배제한다.
3. Terra로 **독립 가상 원형 초안**을 작성하되, 서로 다른 세 갈래 진실과 개별 증거 구성 및 NPC 관계를 완성한다.
4. JSON 사건팩 검증: 필수 필드·중복 원인/증거·현장 관찰/미확인 구분·출처 형식.
5. 법률 검토: 유효 법조문과 주문, 증거 절차, 판결 가능 범위. **판례 출처 존재만으로 검증 통과로 치지 않는다.**
6. 시간·인물·진술·증거 모순 검토 및 사건의 각 진실에 따른 공판~선고 전체 재생 테스트.
7. 승인된 팩만 테스트 세계에서 설치한 뒤, 기획자 승인 및 서버 공유 세계 등록(향후 P3/P4).

## 운영 원칙
- 기존 사건/저장 데이터 변경 없이 확장한다. 같은 원형을 반복 사용하더라도 실제 사건의 사실관계가 구분되어야 한다.
- 보도 사건은 중요도에 따라 **일부만** 뉴스로 시작한다. 일부는 재판까지 오지 않는다.
- 비공개 수사자료와 생성된 `privateTruth`는 언론의 인풋으로 전달하지 않는다.
- AI 호출은 사건 사전 제작·승인 과정이나 중요한 발언에 한정하고, 화면을 열 때 재생성하지 않는다.
- 공개 API 키와 이용조건이 확인되기 전에는 법원/법제처 서비스에 무단 자동 수집을 시도하지 않는다.
