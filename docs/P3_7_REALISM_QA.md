# P3-7 — 전체 사건 분야 현실 고증과 승인 절차

## 모든 신규 사건의 제작 원칙
살인·치사, 성범죄, 폭행, 사기·횡령, 재산·교통, 명예·디지털, 일반 민사, 가족, 전문·의료, 공공·부패 사건은 서로 다른 실제 사건기록 형식으로 구성한다. 자극적인 묘사는 배제하고, 누가·언제·어디서·무엇을·왜 했는지, 어떤 관찰 가능한 흔적이 남았는지를 구체적으로 작성한다.

| 분야 | 필수 개연성 검토 |
|---|---|
| 살인·치사 | 실제 손상·사망 원인, 인과관계, 법의학적 판단의 한계 |
| 성범죄 | 동의/거부 또는 의사결정 능력, 접촉 경위, 의료 감정의 한계 |
| 폭행·상해 | 접촉·폭행의 경위, 상해 유무와 기전, 진료 결과 |
| 사기·횡령 | 돈의 흐름, 처분 권한·기망 행위, 손해·이익 |
| 절도·재산·교통 | 물적·디지털 흔적, 소유·의무, 손해·사고 기전 |
| 명예훼손·디지털 | 원 발언·게시물, 전파 범위, 진실성 및 문맥 |
| 민사 | 계약이나 주의의무, 위반 여부, 손해와 청구 범위 |
| 가족 | 친족·혼인 상태, 법적 관계, 당사자의 선택 |
| 전문·의료 | 당시 요구되는 주의 수준, 결과와의 인과관계, 전문가 감정의 한계 |
| 공공·부패 | 공적 직무, 결재/처분 절차, 이익 관계와 남용 가능성 |

## 구현
- `server/worker/src/case_realism_quality.cjs`: `realism` 작성 요건, 장면 관찰/불확실성 분리, 증거 확보 경위와 한계 분리, 세계별 증거 복붙 및 '원문 확인 필요' 등의 미완성 문구를 검사한다.
- `server/worker/src/terra_case_pipeline.cjs`: 분야별 검수와 기존 성범죄 검수를 결합한다. `draft`는 계속 편집 가능하지만 **`review` 상태에는 상세 고증표가 필수**이고, `makeReview` 및 `admit` 모두 `review`만 받는다.
- 검수 승인 기록에는 **전체 초안의 SHA-256 해시**를 포함한다. 승인 뒤 원문, 숨긴 진실, 증거가 한 글자라도 바뀌면 기존 승인으로 등록할 수 없다. 해시는 편집 후 변경 감지용이지 검수자의 진정성·권한 인증이나 전자서명이 아니다.
- `sensitiveDetailPolicy: "non-graphic"`를 고정하여 선정적·불필요하게 상세한 폭력 묘사를 배제한다.

## 아직 완료되지 않은 것
자동 검사만으로 법률/의학적 정확성을 증명하지 않는다. 판례·법령 공식 출처 대조, 신문 및 선고 완주, 실제 Terra 호출, 운영자 인증, 2인 공유 서버의 원자적 배당, UI 연결은 별도 개발이 필요하다.

기존 `world-sheets/cases` 100개와 `main`, 유저 세이브를 변경하지 않는다. 신규 9건은 계속 `draft`로 유지한다.
