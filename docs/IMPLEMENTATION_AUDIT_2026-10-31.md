# THE VERDICT — 회의 요구사항 대조 및 실구현 감사 (2026-10-31)

## 이번 점검에서 코드 수정 완료
- 사건 화면 열람 시 자동 생성되던 증인 NPC 3명을 '증인 후보 검토' 선택 후 생성하도록 지연. 기존 증인 기록은 보존.
- 다른 재판부 이관 사건을 기존 NPC에게 무작위 연결하던 허위 인과관계 제거.
- 다른 재판부의 임의 결과는 실제 법적 심리·증거 판단 결과가 아닌 '가상 종결 결과'라고 표시.

## 구현되어 있지만 실기기·통합 검증이 필요한 기능
- 시작 화면과 플레이어 1·2 로컬 저장 슬롯.
- 모바일 캐릭터 선택 온보딩(v2.2).
- 기존 100개 사건 원형과 추가 서사·증인·반박 데이터. 사건 고유 데이터의 법률·드라마 품질은 균일하지 않음.
- 재판 연기 사유와 현실 분 단위 대기. 여러 단계의 판결 제한.
- 오전 10시~오후 10시 사건 제안과 하루 4건 수락, 진행 사건 12건 한도.
- 브라우저 자동 저장과 IndexedDB 복구용 스냅샷.

## 아직 완전히 구현되지 않은 핵심 회의 요구사항
1. **기기 간 계정 로그인과 클라우드 자동 동기화:** GitHub Pages와 브라우저 로컬 저장만으로 해결할 수 없음. 인증·서버 DB·세이브 충돌 병합 및 접근제어가 필요.
2. **30~40년 세계 시계의 완전한 전환:** '현실 3시간 = 게임 1일'로 주 단위 시계를 보간하는 과도기이며 일부 기존 주간 개념/오래된 UI가 남음. 기존 생애·급여·일정과 충돌 가능.
3. **다른 재판부의 실제 사건 처리:** 현재는 배당 이관 후 임의 종결 상태만 계산. NPC의 독립된 재판·증거·가족·직업 변화까지 연결된 시뮬레이션은 미완성.
4. **전문성 → 배당 확률:** 완료 사건 수 기반 가중치는 구현되지만, 법원 직위·관할·배당 공정성·복잡 사건 제한까지 반영되지 않음.
5. **100편 수준의 개별 드라마:** 원형·5막·등장인물 역할과 증언은 확대됐지만 서사별 독립적 반전·진실 상태·판결 후 구체적 갈래를 전부 수동 검수하지 못함.
6. **NPC 지연 활성화의 완성:** 증인 후보 지연 생성은 개선했지만 사건 당사자는 수락 후 즉시 생성. 재사용/연계는 제한적.
7. **저장 안정성:** 로컬 2슬롯과 IndexedDB 3스냅샷은 구현. 실제 Safari/Chrome 장기 저장·공간 부족·중복 탭·손상 파일 자동 선택 복구·기기 간 동기화 검증 전.

## 배포 운영원칙
- GitHub commit/Pages 성공과 모바일 기능 검증은 구분한다.
- 서비스워커 캐시 이름을 바꿔도 기존 설치형 PWA에서 즉시 최신 코드로 바뀐다고 보장할 수 없다.
- 사용자의 실제 파일 삭제를 요구하기 전 반드시 게임 내 JSON 백업을 확보한다.
- 자동 생성 자료를 판결의 '입증된 사실'로 표현하지 않는다.
