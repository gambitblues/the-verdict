# THE VERDICT — 베타 안정화 v3.1 (개발 브랜치)

기준: 사용자 감사 2026-10-31. 공개 베타 `main`은 변경하지 않는다.

## 홈 / 태블릿
- 홈 상단 `저장·새 게임`, `SNS` 바로가기와 기존 가상 주간 진행 버튼을 화면에서 제거.
- 현재 실제 시각, 게임 세계 날짜(현실 3시간 = 게임 하루), 다음 사건 제안 시간을 하나의 시계 위젯으로 표시. 내부의 `S.week`는 NPC 생애·연봉·이전 사건의 호환성을 위해 **계산 단위로만 유지**.
- '오늘의 기사' 미리보기와 신규 사건 선택, 진행 사건을 홈의 핵심 흐름으로 배치.
- 태블릿: 기사·여론·법조계 랭킹·메시지·판결 기록·커리어·메모·저장. 법조계 인지도/로펌 순위는 홈에서 태블릿으로 이동.
- 사건팩 관리 메뉴는 일반 사용 UI에서 숨김. JSON 파일 백업은 사용자가 필요한 경우에만 '설정 → 기기 이전'에서 펼쳐 보이도록 함.
- 저장은 매 행동 자동 저장과 태블릿의 단일 '저장' 버튼. 브라우저 종료는 별도 절차가 필요 없음(같은 기기·브라우저 일반 모드 기준).

## 미디어 및 댓글
- 가상 언론사 20곳을 고유한 이름으로 생성, 배당·증거 원본·양측 반박·증언·재판 전망을 다르게 다룸.
- 사건 자료를 기반으로 한 다양한 의견 조합, 최대 90개 게시글 노출. 댓글은 판결 증거와 분리.
- **실제 외부 뉴스 실시간 동기화 아님**. 언론사는 모두 가상 브랜드.

## 법조인 / 사건
- 사건 생성 후 새 담당 검사·변호사 ID를 원래 스토리 심리 단계의 등장인물 참조에 함께 반영.
- 이전 세이브에 이미 저장된 사건도 현재 변론 담당자와 구 ID를 대조해 정정.
- 3단계 심리마다 자료의 원본·진술 모순·대체 가능성 중 판사의 확인 방향을 고르고 기록. 재판 기일 미충족 시 선고 버튼을 비활성으로 표시.
- 100개 사건 시나리오의 사건별 증인 직책·분쟁 증거는 기존 개발팩을 유지. 플레이어용 100개 narrative 제작 지시문 삭제.

## 구조 및 저장
- HTML에서 19개 개별 패치 스크립트 로드를 제거. 기존 엔진 6개 + 검증 가능 런타임 4개를 고정 순서로 로드: `verdict_runtime_v31.js`, `verdict_hearings_v31.js`, `verdict_professions_v31.js`, `verdict_ui_v31.js`.
- 기존 소스 파일은 이력 및 재빌드 재료로 유지하지만, 실행은 묶음 런타임만 수행. **이것은 로딩 안정화 단계이며, 내부에 남아 있는 래퍼 함수를 완전히 모듈화한 리팩터링이 아님.**
- 로컬 세이브 직렬화에서 네트워크/오프라인에서 복구 가능한 기본 100건 사건 원형 팩의 본문을 제외; 사용자 정의 팩·개별 사건·인물·판결·재판 메모는 유지.
- 현재 localStorage는 빠른 부팅을 위한 주 저장소, IndexedDB는 최근 3개 스냅샷 보관용이다. 완전한 IndexedDB 우선 저장/클라우드 동기화는 미완료.

## 검증
- 새 JS 런타임 4개 문법 검사 및 HTML/서비스워커 참조 검증 통과.
- 100개 사건팩 구조·기본 텍스트 검사, 플레이어 노출 제작 지시문 100개 제거 확인.
- 브라우저 자동 QA: 새 커리어 4건 배당, 중복 원형 없음, 20 언론사, 주간 버튼 제거, 모바일 법정 4탭, 심리 방향 기록, 법조계 랭킹 (GitHub Actions, Chromium 390×844).
- 추가 QA: 검사·변호사 증인 신원 충돌 / 명시적 저장 / 새로고침 후 커리어 복원 (CI 실행 결과에 따라 확인).
- 실제 iPhone Safari 테스트와 40년 전체 시계 누적 부하, 100건 서사 품질 수동검수는 미완료.
