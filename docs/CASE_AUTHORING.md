# 사건 시나리오 기획 양식

기획서를 `docs/case-template.json` 모양 그대로 써 주면, 개발에서 아래 파일들로 나눠 넣고 검사(`narrative-qa`)를 돌려 바로 출제 풀에 올린다. 칸 이름은 코드와 똑같으니 영어 그대로 둔다.

| 기획서 칸 | 들어가는 곳 | 게임에서 보이는 곳 |
|---|---|---|
| `meta` | `content-packs/*.json` | 사건 배당 카드(제목·꼬리표·아이콘), 유형별 출제 비율 |
| `story` | `curated/part*.js` | 사건 개요, 막 구성, 선고 뒤 결말, 몇 년 뒤 진실 |
| `profile` · `sex` | `curated/registry.js` | 인물카드 나이·직업·학력, 성별 규칙 |
| `court` · `evidence` · `late` · `witnesses` | `curated/detail*.js` | 쟁점, 증거 카드, 증인 신문, 새 증거, 구형·청구액·결정 |
| `followUps` | `curated/follow*.js` | 재판장 주문(기일 사이 자료 요구·재소환·설명 요구) |
| `party` | `curated/party*.js` | 피고인·당사자 신문 |

완성 예시: `docs/case-examples/criminal-murder-campus-conflict.json`(형사), `civil-shaded-roof.json`(민사), `decision-guardian-signature.json`(결정형). 실제 게임 데이터에서 뽑은 것이라 깊이를 그대로 따라 쓰면 된다.

---

## 1. 먼저 정할 것: 사건 모양과 진실 셋

- **kind**
  - `criminal`(형사): 유죄·무죄와 형량을 정한다.
  - `civil`(민사): 금액을 정한다.
  - `decision`(결정형): 인용·기각만 정한다. 심리 1회 뒤 바로 결정하고 금액은 없다.
- **진실 셋(`truth`)이 모든 것의 뼈대다.** 게임은 새 게임마다 셋 중 하나를 몰래 고정하고, 진실에 따라 달라지는 답과 자료가 그 진실을 따라간다.

  | 키 | 형사 | 민사·결정형 |
  |---|---|---|
  | `did` | 혐의가 맞다 | 청구(신청)한 쪽이 맞다 |
  | `didnt` | 혐의가 틀렸다 | 상대가 맞다 |
  | `reason` | 행동은 있었지만 사정이 있다(감경·정당방위 등) | 일부만 맞다 |

- **그래서 기획에서 가장 중요한 일:** 증인 답, 새 자료, 피고인 답을 진실 셋마다 따로 쓰는 것. 셋이 서로 **말이 맞아야** 한다. 같은 진실 안에서 증인 2와 피고인과 새 증거가 같은 그림을 그려야 판사가 추리할 수 있다.

## 2. 칸별 분량 (검사 기준 — 모자라면 배포 불가)

| 칸 | 필요한 양 |
|---|---|
| `story.claims` | 정확히 2문장 (양쪽 주장) |
| `story.acts` | 정확히 4개 (발단·전개·위기·절정) |
| `story.truth` | `did`·`didnt`·`reason` 셋 다 |
| `story.endings` | 형사 `convict`·`acquit`, 민사·결정형 `claimant`·`respondent` |
| `court.issues` | 2~3개 (`i1`~`i3`). 모든 증거·질문·주문은 이 중 하나에 묶인다 |
| 형사 `court.charge` · `demand` | 법정형 범위(년) 안의 구형. 벌금 구형이면 `charge.fine`에 상한이 있어야 함 |
| 민사 `court.claim` | `amount`(만 원) ≥ `fair` 범위의 최대값 |
| 결정형 `court.decision` | 7칸 모두 |
| `evidence` | 정확히 3개, 12칸 모두 |
| `late` | 1개 (공판 중 도착하는 증거) + `reason` + `rebut` |
| `witnesses` | 정확히 3명. 증인마다 질문 3~4개, 그중 처음부터 열린 질문 2개 이상 |
| 진실별 답 | 사건 전체에서 진실에 따라 달라지는 증인 답이 2개 이상 (실제로는 증인마다 1~2개 권장) |
| `followUps` (형사 살인·성범죄) | 6개 이상 |
| `followUps` (그 밖의 형사·민사) | 5개 이상 |
| `followUps` (결정형) | 2개 이상, 모두 `"now": true`(그 자리 질문) |
| `party` | 질문 3개, 각 질문에 진실 셋의 답 |
| `court.rebut` · `closing` | 각 1~2문장 |
| `profile` | A·B 직업과 나이 범위는 꼭. 학력·혼인·자녀는 이야기에 필요하면 |

## 3. 증거 한 장 (`evidence`, `late`, 주문으로 받는 자료)

| 칸 | 뜻 | 좋은 예 |
|---|---|---|
| `title` | 증거 이름 | 펜션 계단 조명 기록 |
| `kind` | 종류. 화면 그림(영상·메신저·감정서·통화기록 등 11가지)이 이 말로 정해진다 | 시설 관리 기록 |
| `by` | 낸 쪽 | 검찰 / 변호인 / 원고 / 피고 |
| `when` | 자료의 시점 | 사건 당일 23:40~00:30 |
| `excerpt` | 원문 발췌. 기록 그대로의 말투로, 숫자와 시각이 있으면 좋다 | 23:51 켜짐 / 23:54 꺼짐 … |
| `shows` | 이 증거가 말하는 것 | 추락 시각 전후로 조명이 꺼져 있었다 |
| `caveat` | 한계 | 꺼졌다는 사실은 사고와 범행 모두 설명할 수 있다 |
| `how` | 확보 경위. 판사가 믿을지 판단하는 재료 | 사흘 뒤 관리 PC에서 내려받음, 시계 미보정 |
| `check` | 판사에게 주는 힌트 | 부회장이 말한 10분과 맞춰 보세요 |
| `issue` | 묶이는 쟁점 | i2 |
| `side` | `p` 검찰·원고 쪽 / `d` 피고인·피고 쪽 / `n` 중립 | d |
| `flaw` | 약점 종류. 증거 반박 장면에 쓰인다 | `none` · `timing`(시각) · `source`(출처) · `illegal`(위법 수집 → 배제 가능) |

- 주문으로 받는 자료는 `excerpt`·`shows`·`side`를 진실별 `{did, didnt, reason}`로 써도 된다. 같은 자료를 요구해도 진실에 따라 내용이 다르게 나온다.

## 4. 증인 (`witnesses`)

- `role`: 관계와 직업이 드러나게 쓴다(예: 펜션 관리인). 이름은 쓰지 않는다. 나이와 경력은 역할에서 자동으로 맞춘다.
- `story`: 배경 2문장.
- `stake`: 이해관계. 증인의 태도(협조·회피·번복)를 계산할 때 쓰인다.
- `says`: 첫 진술. 1인칭이고, 끝에 마침표를 찍지 않는다.
- `lead`: 유도 질문. 상대가 이의를 거는 장면에 쓰인다.
- `q`: 판사가 고르는 질문.
  - 진실과 상관없이 답이 같으면 `a`에 문자열을 쓰고 `side`를 붙인다.
  - 진실에 따라 다르면 `a`에 `{did, didnt, reason}`을 쓴다.
  - 숨은 질문은 `"hidden": true`로 두고, 그 질문을 여는 질문에 `"next": ["q4"]`를 쓴다. 꼬리 질문은 이렇게 만든다.

## 5. 재판장 주문 (`followUps`) — 2회차 이후 재미를 만드는 곳

주문은 판사가 기일 사이에 "이 자료를 내라 / 이 사람을 다시 불러라 / 이걸 설명하라"고 하는 것이다. 노드 하나가 주문 하나다.

| `type` | 뜻 | 반드시 함께 쓸 칸 |
|---|---|---|
| `records` | 기록 제출 (통화·출입·결제 내역 등) | `evidence` |
| `original` | 원본 제출 (캡처 대신 원본, 원본 파일 정보 등) | `evidence` |
| `alibi` | 알리바이 자료 | `evidence` |
| `expert` | 감정 의뢰 | `evidence` |
| `compare` | 두 자료 대조 | `evidence` |
| `witness` | 새 증인 신청 | `witness` (`role`·`story`·`stake`·`lead`·질문 3개) |
| `recall` | 이미 나온 증인 재소환 | `recall: {"w": 증인번호(0~2), "q": [새 질문 2개 이상, 진실별 답 1개 이상]}` |
| `explain` | 양쪽에 설명 요구 | `answer: {"p": "...", "d": "..."}` |

- **`to`**: `p` 검찰·원고 / `d` 변호인·피고 / `both`.
- **`day`**: 이 기일부터 열린다(1~4). 5기일부터는 `recall`·`explain`만 나온다.
- **`after`**(열리는 조건, 선택):
  - `{"heard":"1:q2"}`: 증인 1의 q2를 들은 뒤 (증인 번호는 0부터)
  - `{"got":"n1"}`: n1 자료를 받은 뒤
  - `{"miss":"n1"}`: n1이 없거나 거절된 뒤
  - `{"done":"n1"}`: n1을 결과와 상관없이 처리한 뒤
  - `{"contra":"i1"}`: i1 쟁점에서 진술이 엇갈린 뒤
  - 여러 조건 묶기: `{"any":[…]}` 하나라도 / `{"all":[…]}` 모두
  - 조건에는 **앞에 쓴 노드만** 쓸 수 있다.
- **`have` / `none`**: 어떤 진실에서는 자료가 아예 없으면 `"have":{"didnt":false}`로 표시하고, `none`에 "그런 기록은 없습니다"류 답을 쓴다.
- **형사에서 변호인에게 증거를 요구하는 주문**은 거절할 수 있다(입증 책임이 없으므로). 그래서 `none` 답이 반드시 있어야 한다.
- **없음·거절 뒤 길:** 위 두 경우처럼 빈손으로 끝날 수 있는 노드에는 `{"miss":"그 노드"}`로 열리는 다른 길 노드가 꼭 하나 있어야 한다.
- **필수 구성:** `recall` 1개 이상, `explain` 1개 이상, 3기일 이후 노드(`day`≥3이거나 `got`·`miss`·`done` 조건) 1개 이상.
- **결정형:** 모든 노드에 `"now": true`를 붙이고 주로 `explain`으로 쓴다. 심리 자리에서 바로 묻는 질문이 된다.

## 6. 당사자 신문 (`party`)

- 형사는 피고인(`"who":"A","role":"피고인"`)에게, 민사·결정형은 한쪽 당사자에게 묻는다.
- 질문 3개, 각각 진실 셋의 답을 쓴다.
- `side`(선택): 그 답이 어느 쪽으로 기우는지. 당사자 말은 증거가 아니라서 기본은 중립이다.
  - `p` / `d`: 답에서 무언가 새어 나올 때만 쓴다.
  - `m`: 판단을 어렵게 하는 사정.
- 형사 피고인은 20% 확률로 진술을 거부하고, 거부는 불리하게 계산되지 않는다. 답을 쓸 때 이 점은 신경 쓰지 않아도 된다.

## 7. 인물 고증 (`profile`, `sex`)

- **`profile`:**
  - `job`: 직업
  - `age`: `[최소, 최대]` 나이 범위
  - `deg`: 학력
  - `mar`: 혼인
  - `kids`: 자녀 수
  - 두 사람 나이 관계가 중요하면 `"younger":"A"`(A보다 어림), `"same":"A"`(A와 동갑대)를 쓴다.
- **`sex`:** 이야기가 성별에 기댈 때만 쓴다. 쓰지 않으면 무작위다.
  - `"A":"여"`: A의 성별을 고정
  - `"AB":"diff"` / `"same"`: 두 당사자가 이성 / 동성
  - `"W":{"1":"diffB"}`: 증인 1이 B와 이성 (`sameA`·`sameB`·`diffA`·`diffB`)
- 성범죄·스토킹·부부·연인·이혼·양육·불륜 사건은 따로 쓰지 않아도 두 당사자가 자동으로 이성이 된다.

## 8. 문장 규칙 (검사에 걸리는 것)

- **인물 부르기:**
  - 당사자 `{A}` `{B}`, 증인 `{W1}` `{W2}` `{W3}`, 변호사 `{L}`. 이름은 게임이 넣는다.
  - 이름 뒤 조사는 항상 `{A|이}` `{A|은}` `{A|을}` `{A|과}` `{A|으로}` 꼴로 쓴다. `{A}가`처럼 쓰면 이름에 따라 틀린다.
  - 형·오빠·누나·언니 호칭은 `{A>B}`(B가 A를 부르는 말)로 쓴다.
- **성별을 단정하는 단어 금지:** 남자, 여자, 남성, 여성, 아빠, 엄마, 남편, 아내, 장남, 장녀, 누나, 오빠, 언니, 사위, 며느리.
  - 다른 낱말 속에 섞여도 걸린다. 쫓아**내** → 아내, 참**여자** → 여자, 심**사위**원 → 사위.
  - 증인 `role`에서는 허용한다.
- **쉬운 말:** 고등학생이 읽을 수 있게 쓴다. 게이지 수치는 쓰지 않는다. 법률 용어는 꼭 필요한 것만, 풀어서 쓴다.
- **사건 사이 반복 피하기:** 다른 사건과 같은 문장이 반복되면 검사 수치가 올라간다.

## 9. 넘겨줄 때

- 사건 하나에 JSON 파일 하나로 준다.
- 칸을 비워 두면 개발에서 채우지 않고 되묻는다. 단, 다음 칸은 비워도 개발에서 맞춰 넣는다.
  - `meta.icon`, `meta.tag`
  - `profile.deg`
  - 형사 `charge`의 법 조문
- 새 사건이 들어가면 출제 풀 건수와 유형 비율이 바뀐다. 몇 건을 어느 유형으로 추가하는지 함께 알려 주면 된다.
