# THE VERDICT — 다음 베타 개발본 · UX/법정 콘텐츠 QA 기록

작업 브랜치: `develop` (공개 `main` 미배포)
릴리스 후보: Character & Case Editorial v2.4

## 반영
- 판사 얼굴 생성: 성별 표현/얼굴형/피부톤/헤어/안경/법복, `S.judgeAvatar` 1개로 시작 화면·홈·법정 아바타 통일.
- 100개 사건팩: 사건 개요 2줄형 UI, 사건 장소/행위/동기/혐의·가상 구형/반대 논점을 개별 원형 ID에 연결.
- 17개 사망 사건 및 16개 성범죄 원형: 유형·도구·관계·법의학 쟁점을 별도의 상세 자료로 정의.
- 형사 검사/변호인 전문과 민사 원고/피고 서면: 서명된 입장(가상), 주장과 반론, 증거 한계를 구분.
- 증인: 핵심 역할(예: 시험 감독관)을 이름과 함께 상단에 표시. 긴 생애 정보는 선택적으로 펼침.
- 기존 사건 노출 시 반복적으로 출력되던 장문 도입·중복 5막 요약 일부 제거. 기일 업데이트는 별도 접힘 메뉴.

## 검사 결과
- 100 사건 원형 ↔ 100 서면/쟁점 레코드 ID 1:1 일치.
- 100건 모두 장소/시점/행위/동기/반박/증인 역할 3명 포함.
- 33건 상세 법의학 기록 참조가 유효함.
- 새 JS 문법 검사 통과.
- 100건 모의 법정 렌더링 검사: 기존 반복 문단 제거, 양측 의견서 버튼 및 증인 역할 표기 100/100 통과.
- 예시 익명 게시판 사건: AI 스마트안경 혐의 확인, '임준영 · 시험 감독관' 프로필 모의 렌더 성공.
- 아바타 모의 검사: 여성형+안경 선택 후 상태 저장, `avatar('self')` 증명사진 렌더링 성공.

## 아직 검증 및 보완 필요
- 실제 iPhone/Android Safari/Chrome 구동·스크롤·인물 카드·서면 버튼 e2e 실기기 테스트.
- 100개 서면의 개별 법률 요건과 구형 적정성에 대한 전문 검수. **현재 혐의와 구형은 가상·잠정 설정**.
- AI 생성 추론과 객관적 증거 사이 모순을 제거하기 위한 전체 사건별 플레이 QA.
- 특정 의료/법의학 기록은 가상 사건용이며 피해자의 진술·검사 결과 중 어느 한 부분도 단독으로 동의 여부를 확정하지 않음.
- 기존 진행 중인 사건의 최초 생성 데이터와 새 상세 원형 간 설정 차이가 있을 수 있으므로 세이브 유지 및 신규 배당 전환 테스트 필요.

## 배포 지침
사용자 일괄 배포 명령 전까지 `main`에 병합하지 않는다.
