# THE VERDICT — Advanced 100건 연구·작성 작업대장

## 목표
**형사 50 / 민사 25 / 가사 20 / 행정 5건**. 모든 사건은 개별적으로 출처 확인 → 법적 쟁점 검증 → 구체적 시공간·행위·피해·인물·증거 기획 → `did/didnt/reason`의 불변 진실 → 증인·공방·후속 세계관 → 시드·UI 전수 QA를 거친다.

## 주의
기존 `content-packs/court-editorial-100-v1.json`의 100개 이야기는 형사 71·민사 29개다. 이들은 **기획 후보 목록**이지 실재 판례의 100개 원형이나 Advanced 완성 콘텐츠가 아니다. `node tests/advanced-research-backlog.cjs > backlog.json`로 이를 조사 대장으로 내보낼 수 있다. 미확인 출처는 `unverified`로 유지하며 결코 검증한 것으로 표시하지 않는다.

## 사건별 승인 게이트
- 공개 판례와 기사 원문: 제목·사건번호·선고법원·선고일·확인 가능한 공식 URL·확인일 저장
- 출처의 실제 사실과 게임용 창작 사실 구분. 실존 피해자·피고인 등 개인 식별정보 사용 금지
- 구체적인 가상 장소명, 날짜, 시각, 횟수, 피해액·부상·행위 유형 및 원본 자료의 한계 작성
- 실제 사건의 형식에 맞는 적용 법률 및 사건 당시 법령 시행일 확인
- 각 진실의 타임라인과 장치 시계, 증인 관찰 범위, 증거 출처·확보 경위, 검사·변호인의 공방 작성
- 법률상 가능한 후속 사건만 시뮬레이션 대상으로 제안. 미래 분쟁은 발생하지 않을 수도 있음
- QA 통과 전에는 `published` 표시와 실제 게임 배포 금지

## 구현 구분
`advanced_case_schema.js`는 소스 확인 증빙을 **데이터 필드 존재 여부**로 검사한다. 실제 링크의 법률적 진위는 자동 보장하지 않는다. `dev/advanced-pilot/advanced_pilot.html`은 정식 커리어 UI가 아닌 별도 개발용 시뮬레이터다. 후속 사건 엔진 `advanced_world_engine.js`는 후보 이벤트를 결정하지만 소송의 적법한 요건·실제 출산 여부를 자동 판단하지 않는다.
