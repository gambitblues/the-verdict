# trash/

필요 없어진 파일·중복 파일을 지우기 전에 잠시 옮겨 두는 곳입니다(2026-11-10 기획자 요청).

- 게임은 이 폴더를 읽지 않고, 공개 사이트(main)에도 올라가지 않습니다(`scripts/release-main.sh`의 DEV_ONLY).
- 옮길 때는 원래 경로를 그대로 살려 둡니다. 예: `trash/tests/old-check.mjs`
- 다시 쓸 일이 없다고 확인되면 이 폴더에서 지웁니다.
- 세이브 기록은 이 저장소가 아니라 각 기기와 Supabase에 있습니다. 서버 세이브를 정리할 때도 지우지 않고 보관 표(`save_backups`)를 거칩니다.
