# 세계 시트 (world-sheets)

사건마다 "실제로 무슨 일이 있었는가"를 세 세계(did · didnt · reason)로 고정해 두는 곳.
법정에서 누가 무엇을 말하는지는 여기 쓰지 않는다. 그건 엔진이 이 사실과 인물 성향으로 만든다.

## 가장 쉬운 방법: 씨앗만 적기
`seeds.md` 맨 아래에 사건 씨앗(판례·죄명·무슨 일·갈리는 지점, 10줄 안팎)을 추가하면 Claude가 시트를 완성해 게임에 넣는다. 아래 '올리는 법'은 시트를 직접 쓰고 싶을 때만.

## 올리는 법
1. `template.json`을 복사해 `cases/<사건id>.json`으로 저장한다. 파일 이름과 `id`를 같게.
2. 채워서 develop 브랜치의 `world-sheets/cases/`에 올린다. 한 사건에 파일 하나.
3. 올리면 자동 검사(`node tests/world-sheets.test.cjs`)가 돈다. 실패하면 이유가 한국어로 나온다.
4. 다 쓰면 `status`를 `ready`로 바꾸고 "검수해줘"라고 알려 준다.
   상태: `draft` 쓰는 중 → `review` 검토 요청 → `ready` 게임에 넣어도 됨.
   `review`·`ready` 시트는 배포 때 `node tests/build-sheets.cjs`로 게임 데이터(`world_sheets.js`)에 들어가 배당 후보가 된다(Claude가 검수하며 실행). `draft`는 게임에 안 들어간다.
   `draft`는 내용 문제를 경고로만 알려 주고, `review`·`ready`부터는 실패로 막는다: 자료에 숨은 진실 문장이 그대로 들어감, 자료에 평가 문장('뒷받침한다', '단정할 수 없다' 등), 너무 짧은 행위, 행위와 같은 동기, 여러 사건에 똑같이 쓰인 문장.

견본: `cases/clinic-001.json` (늘밝은성형외과 사건, 기획 예시).

## 꼭 지킬 원칙
- **세계층은 바뀌지 않는다.** 진실, 발생 일시·장소·순서, 동기와 원인, 증거 원본 내용, 증거 확보 경위, 증인이 실제로 본 것과 못 본 범위, 인물이 한 일과 아는 것, 인과관계.
- **법정에서 바뀌는 것은 쓰지 않는다.** 법정 진술, 자백·부인, 반성문, 합의, 변호인 전략, 판결.
- **공통 사실(`common`)에는 세 세계 모두에서 참인 것만.** 세계마다 다른 것은 `worlds`로.
- **자료(`records`)는 세 세계 모두에 내용을 쓴다.** 같은 자료가 세계에 따라 어떻게 다르게 나오는지가 판사의 추리 길이다.
- **증거 하나로 끝나지 않게.** 처음 제출되는 자료 하나만으로 세 세계가 다 갈리면 검사가 경고한다.
- **기기 시계 오차**는 `devices.clockOffsetSec`에 적고, 그 기기 자료에는 화면 시각과 실제 시각을 함께 적는다.

## 얼마나 했는지 쓰기 (2026-11 확정)
- `act`와 `sentencing`은 **판결문 '범죄사실' 수준으로 구체적으로** 쓴다. 무엇을, 어떤 수단으로, 얼마나(시간·횟수), 어떤 상황에서(주거 침입·가족 앞·촬영·특정 행위 강요·도구), 어떤 결과(상해 부위·치료 기간·정신적 피해)였는지. 같은 죄명이라도 여기서 형량이 갈린다.
- 문체는 사실을 적는 판결문체. 감각적·선정적 장면 묘사는 쓰지 않는다.
- 미성년자가 관련된 성적 내용은 쓰지 않는다. 마약 제조법·흉기 제작·증거 인멸 요령처럼 따라 할 수 있는 실행 방법도 쓰지 않는다.
- `sentencing` 칸: means 수단 / degree 정도 / count 횟수·기간 / setting 상황 / harm 피해 결과 / victim 피해자 취약성 / planning 계획성 / after 사후 태도. 형사 사건은 세 세계 모두 채운다(범행이 없는 세계는 '해당 없음'과 실제로 일어난 일).

## 실제 판례로 쓸 때 (`source.type: "real_case"`)
- 공식 공개된 판결(법원·법제처 등)만. 법원, 사건번호, 선고일, https 원문 주소, 열람일을 적는다.
- `usedFacts`: 판례에서 가져온 사실. 나머지는 모두 창작이다.
- 실명·실제 상호·주소·피해자를 알아볼 수 있는 조합은 쓰지 않는다. 바꿨으면 `fictionalized: true`.
- 판례의 법리(구성요건·증명책임·절차)는 바꾸지 않는다. 사실관계만 각색한다.
- 이 폴더는 공개 사이트(main)에 올라가지 않는다. 다만 GitHub 저장소가 공개 상태라 저장소에서는 보인다.

## 칸 설명 (요약)
| 칸 | 쓰는 것 |
|---|---|
| `card` | 플레이어가 보는 사건 카드. 형사 `charge` / 민사 `claim` / 결정형 `decision` 중 하나 |
| `people` | A 피고인·피고, B 고소인·원고, W1… 증인. 나이·직업·가족·상태·성향(말로). 증인이 누구 편으로 기우는지 `stake`로 판단이 안 되면 `leans`: "A" · "B" · null |
| `places`, `devices` | 장소와 기록을 남기는 기기(시계 오차 포함) |
| `common` | 날짜와 세 세계 공통 시간표·사실 |
| `records` | 자료 목록. `first: false`면 `unlock`에 어떤 주문으로 나오는지 |
| `worlds.did/didnt/reason` | 행위·동기·원인, 그 세계만의 시간표, 자료에 실제로 담긴 내용, 증인이 본 것, 인물이 아는 것 |
| `traps` | 오판을 부르는 함정 |
| `screen` | 화면 문장에 쓸 말 / 피할 묘사 |
| `open` | 아직 못 정한 것 |

## 성인 성범죄 사건 현실 고증 — 신규 제작 필수 검수 (P3)
- 강간, 준강간, 강제추행, 직장 내 성희롱, 동의 여부가 다투어지는 만남, 허위 신고가 주장되는 사건은 **서로 다른 유형**으로 설계한다. 모든 무죄 사건을 '무고'로 연결하지 않는다. 원나잇은 관계의 형태일 뿐 동의 여부를 정해주지 않는다.
- **물리적 강제력 주장:** 체격과 힘을 수치로 단정하지 말고 공간 구조·행동 가능성·시간 흐름·의복/주변 물건의 상태·제3자 청취 범위·사건 직후 관찰 기록이 서로 모순 없는지 검증한다. '손목을 잡았다'라는 한 문장만으로 다른 행동이 모두 가능했다고 설명하지 않는다. 폭력 상황은 감각적·선정적 묘사 대신 판결문 수준의 사실과 관찰 가능한 흔적으로 쓴다.
- **진정·음주 등 의사결정 능력이 문제인 상황:** 투약·진정/의식 상태 관련 실제 기록, 관찰자가 본 반응, 의료진의 관찰 한계, 법적 구성요건을 각각 확인한다. 단순히 음주 사실만으로 무능력이나 동의 부재를 단정하지 않는다.
- **손상 고증:** 폭력의 양상에 따라 손상과 진료·회복 상황이 달라질 수 있으나 **상해가 반드시 발생하거나 남는 것은 아니다.** 상처가 없다는 사실은 동의나 허위 신고의 증거가 아니고, 상처가 있다고 가해자·범행 형태가 자동 확정되는 것도 아니다. 진료 시점·조사 경위·기저 상태와 감정 한계를 분리한다.
- **DNA·체액:** 검출 여부, 검체 채취 부위, 감정 결과, 혼합 시료 여부, 대안적인 전이·접촉 경위 등을 구별한다. DNA가 검출돼도 접촉 당시의 동의·고의·시각 및 특정 범죄의 성립은 별도의 증거로 판단한다.
- **허위 신고 주장:** 기억 오류·증거 부족·무죄 판단과 **고의적 허위 신고**를 구분한다. 사건마다 신고 직후 행적과 외부 기록을 대조하고, 피해자/피고인 어느 한쪽의 주장을 성별 고정관념으로 확정하지 않는다.
- **세 세계 정합성:** `did/didnt/reason`의 행위 경위, 의학 소견, 증거 출처, 증인 관찰, 사건 후 생활을 각각 독립적으로 작성한다. 논점마다 다른 증거의 해석은 가능하지만 동일 세계 안의 시간표와 물리적 사실은 모순되면 안 된다.
- **Terra 입고:** 신규 `verdict-terra-candidate/v1` 사건에서 `card.category: sexual`이면 `sexualRealism` 검수 항목을 의무화한다. `server/worker/src/sexual_case_quality.cjs`에서 형식·핵심 정보의 존재를 확인한다. **검수기를 통과해도 의학적·법률적 진실성이 보증되는 것은 아니므로 사람의 최종 검수가 필요**하다. 기존 `world-sheets/cases` 사건은 자동 변경·차단하지 않는다.
