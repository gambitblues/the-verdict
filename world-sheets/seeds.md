# 사건 씨앗 (기획자 → Claude)

새 사건 아이디어를 여기에 **아래로 계속 추가**하면 됩니다. 한 사건에 10줄 안팎이면 충분합니다.
Claude가 씨앗마다 세계 시트(`cases/<id>.json`)를 쓰고, 검사·엔진 수백 판을 돌린 뒤 게임에 넣습니다.
다 만든 씨앗은 Claude가 제목 줄 끝에 `→ adv-cr-016 (게임 반영 v8.x)`처럼 표시합니다.

- 이 폴더는 main(공개 사이트)에 올라가지 않습니다. 판례 번호·기사 링크를 적어도 됩니다.
- 실명은 적지 않아도 됩니다. 게임에서는 이름이 모두 새로 만들어집니다.
- 칸을 다 채울 필요는 없습니다. **판례/출처, 죄명, 무슨 일, 갈리는 지점** 네 가지만 있으면 됩니다.
- 성범죄 사건도 판결문 수준(무엇을 어떻게 얼마나)으로 적으면 됩니다. 장면 묘사는 필요 없습니다.

## 양식 (복사해서 맨 아래에 붙여 쓰기)

```
## 제목(가제):
- 판례/출처: (법원·사건번호 또는 기사 링크, 없으면 '창작')
- 형사/민사:
- 죄명 또는 청구:
- 무슨 일이 있었나: (두세 문장)
- 판단이 갈리는 지점: (예: 고의냐 과실이냐 / 신호가 바뀌기 전이냐 후냐 / 동의가 있었나)
- 꼭 넣고 싶은 증거·장면: (선택)
- 세 갈래 방향: (선택) 했다 / 안 했다 / 했지만 사정이 다르다 — 각각 한 줄
- 메모: (선택) 분위기, 인물, 피하고 싶은 것 등
```

## 예시

## 제목(가제): 새벽 편의점의 거스름돈
- 판례/출처: 창작
- 형사/민사: 형사
- 죄명 또는 청구: 강도상해
- 무슨 일이 있었나: 새벽 3시 편의점에서 손님과 점원이 거스름돈 문제로 다투다 점원이 넘어져 손목이 부러졌다. 손님은 계산대의 돈 일부를 들고 나갔다.
- 판단이 갈리는 지점: 돈을 뺏으려고 민 것인가, 다툼 끝에 밀친 뒤 덜 받은 거스름돈만 가져간 것인가
- 꼭 넣고 싶은 증거·장면: 계산대 CCTV에 소리가 없음, POS 기록상 거스름돈이 실제로 덜 나감
- 세 갈래 방향: 했다 = 처음부터 돈을 노림 / 안 했다 = 넘어진 건 점원이 미끄러진 것 / 사정이 다르다 = 밀친 건 맞지만 가져간 건 덜 받은 거스름돈만
- 메모: 점원은 혼자 일하는 야간 아르바이트생
